TEST_PLAN.MD

A tester's read on the product

I'm a QA Tester based in Nairobi, building toward a QA Engineer role — a BBIT graduate from Dedan Kimathi University of Technology who came to quality assurance through building things first.

That front-end and web development background is what shapes how I test: I don't just click through a checklist, I think about what the code is actually doing underneath — which is how a broken auth flow or an edge case in a form validator gets caught before it ships.

My process: read the requirement like a spec, write test cases before I touch the product, execute methodically, and file bug reports a developer can act on without asking a follow-up question.

  • Manual & Exploratory Testing
    Functional, UI, regression and cross-browser testing across web applications.
  • API Testing with Postman
    Collections, environments, pre-request scripts, and assertion writing with pm.test() & pm.expect().
  • Test Case Design & Planning
    Turning requirements into structured test plans with clear pass/fail criteria.
  • Bug Reporting & Tracking
    Clear, reproducible defect reports that developers can action without back-and-forth.
  • Code Quality Audits
    Static analysis with SonarQube to flag quality and maintainability issues early.
